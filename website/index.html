Audio player for Linux and Android

Your music, in your color.

Kvant is a clean, lightweight Material 3 audio player. It plays your files and folders, lets you tune how it looks, and leaves everything else out.

Everything it does.

This is the whole list. Kvant opens your music and plays it, and every part of it looks and moves like Material 3.

  • Files or whole foldersPlay a single file, or open a folder. It's scanned recursively and becomes the queue.
  • A queue that stays out of the wayPut it on the left or right, or collapse it. On narrow windows it becomes a drawer.
  • The squiggly progress barIt settles into a flat line when paused. Set its height, wavelength and speed, or switch it off.
  • One accent, a full color schemeLight, dark or follow the system, with any accent color you like.
  • Drag and dropDrop files and folders onto the window to add them to the queue.
  • Media keys and widgetsMPRIS on Linux for media keys, desktop media widgets and playerctl. Notification and lock screen controls on Android.
  • Open with KvantOn Linux, opening a file from your file manager reuses the window that's already open.
  • Cover artEmbedded artwork, or a cover.jpg / folder.jpg next to the files.
And nothing else.

Kvant has no network code at all. There's no account, no streaming service, no library database and no telemetry. On Android it doesn't even ask for internet access.

Get the APK

AppImage

Any distro

Qt is bundled, so it also runs on older distros.

chmod +x Kvant-*-x86_64.AppImage
./Kvant-*-x86_64.AppImage
Download .AppImage

Flatpak

Any distro

Needs the Flathub remote for the KDE runtime: flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

flatpak install --user ./Kvant-*.flatpak
flatpak run io.github.proshiv85_byte.Kvant
Download .flatpak

Debian / Ubuntu

Debian 13, Ubuntu 26.04+

Older releases like Ubuntu 24.04 ship a Qt that's too old. Use the AppImage or Flatpak there.

sudo apt install ./kvant_*_amd64.deb
Download .deb

Fedora

.rpm

The file name says which Fedora it was built for (fc44 = Fedora 44). It works on that version and newer.

sudo dnf install ./kvant-*.rpm
Download .rpm

Build from source

Needs Qt 6.8 or newer (base, declarative, multimedia with a backend such as qt6-multimedia-ffmpeg), TagLib 2.0 or newer, and CMake.

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr
cmake --build build
sudo cmake --install build

The Android app (Kotlin and Jetpack Compose, in android/) needs JDK 17+ and the Android SDK:

cd android
./gradlew assembleDebug
